## 🔧 Troubleshooting

If you experience issues, try these common fixes:

**Game won't start:**
- Right-click the file and select "Run as administrator"
- Make sure your Windows is fully updated
- Restart your computer and try again

**Black screen or graphics issues:**
- Update your graphics card drivers from the manufacturer's website
- Lower your display resolution temporarily
- Close other programs that use heavy graphics (browsers, streaming apps)

**Audio problems:**
- Check that your speakers/headphones are plugged in correctly
- Set your default audio device in Windows Settings

**Game runs slowly:**
- Close background applications
- Lower in-game graphics settings if available
- Make sure your laptop is plugged in (not on battery)
